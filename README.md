# SmartPosition（Web版）

株式のナンピン・分割買い下がり（E1・E2・E3）で、**破産リスクを抑えながら、第2利確目標 P2 での全決済がプラスになる購入株数（1株単位）** を自動で計算し、利確・損切の軌道マップを描くブラウザ用ツールです。Android版 SmartPosition と同じ計算ロジック・画面構成をWebに移植しています。

- インストール不要。ブラウザで開くだけで使えます（Chrome / Edge / Firefox / Safari）
- 入力内容と保存した計画は **お使いのブラウザ内（localStorage）だけ** に保存され、サーバーへは送信されません
- 本ツールは計算補助であり、投資助言ではありません

## 使い方

1. **INPUT 1**: 「総額の損失許容額」と n（分割係数）を入れると、本トレードの許容損失額（総額 ÷ (3n+n)）が出ます
2. **INPUT 2**: ティッカー、現在値、P1・P2・L1（利確・損切）と E1・E2・E3（買い）の価格を入力します
   - 3段モード: P1 > E1 > P2 > E2 > E3 > L1
   - 2段モード: P1 > E1 > P2 > E2 > L1
3. 株数・平均取得単価・6パターンの Exit 損益・軌道マップが即座に更新されます
4. 画面下部の **玉数配分バランス** スライダーで、E1重視 ↔ 下値（E2・E3）重視を調整できます
5. ±ボタンで1株単位の手動調整ができます（「最適値に戻す」で自動計算に復帰）
6. 「この銘柄の計画を保存」で保存し、「保存済み銘柄」タブで検索・読込・削除できます
7. 別のPCやブラウザへ移すときは、「バックアップを書き出す」で JSON を保存し、移行先で「バックアップを読み込む」を使います

## 計算ルール

- 全損切時の総損失: N1×(E1−L1) + N2×(E2−L1) + N3×(E3−L1) ≤ 本トレード許容損失額
- E1・E2 の加重平均取得単価 ≤ P2（E2まで買い下がっても、P2で全決済すれば利益が出る）
- E1〜E3 の加重平均取得単価 ≤ P2
- 予算が小さく上記を満たせない場合は 0株 とし、警告を表示します
- 金額は整数（四捨五入）、株価・平均単価は小数2桁まで表示します

## ローカルで動かす

ビルドは不要です。`index.html` をブラウザで直接開くか、簡易サーバーで配信します。

```bash
python -m http.server 8000
```

## テスト

計算エンジン（`js/engine.js`）のテストは Node.js 18 以上で実行できます（追加パッケージ不要）。

```bash
node --test tests/engine.test.cjs
```

## ファイル構成

```
index.html        画面の骨組み
css/style.css     配色（ダーク / ライト）とレイアウト
js/engine.js      計算エンジン（Android版 ScaleEntryCalculatorEngine の移植）
js/chart.js       TACTICAL PRICE MAP の Canvas 描画
js/app.js         状態管理・画面更新・localStorage 保存
tests/            計算エンジンのテスト
```

## 更新するとき

`index.html` の `css/style.css?v=3`・`js/*.js?v=2` の番号を上げてください。ブラウザに古いファイルが残って新旧が混ざるのを防ぎます。
